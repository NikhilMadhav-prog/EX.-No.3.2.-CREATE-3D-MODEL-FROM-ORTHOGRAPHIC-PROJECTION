# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM:

To design and draft the given orthographic engineering drawing with accurate dimensions using
Autodesk Fusion 360 and convert it into a three-dimensional solid model.

## REQUIREMENTS:

→Autodesk Fusion 360 (Education License).
→Windows 10 or a compatible Windows operating system.
→Computer system capable of running 3D CAD modelling software.
→Stable internet connection for accessing Autodesk Fusion services.

## PROCEDURE

**1. Create a new design**

Open Autodesk Fusion 360 and create a new design. Set the measurement units to millimetres (mm) and save the file with a suitable experiment name.

<img width="1056" height="682" alt="New Part" src="https://github.com/user-attachments/assets/bdb5ba84-c9e6-4c7f-81ca-b41bf418648e" />

<img width="1061" height="567" alt="Save" src="https://github.com/user-attachments/assets/916f2016-ab96-44d8-b535-48be63321fb4" />

**2. Start the base sketch**

Select the XY plane and choose the Create Sketch option. Draw the initial profile of the base plate using the Line and Arc tools.

<img width="318" height="396" alt="Sketch Plane" src="https://github.com/user-attachments/assets/568111a7-abdb-4e1e-8f2a-be3419149cc9" />

<img width="540" height="691" alt="Create Sketch" src="https://github.com/user-attachments/assets/bd99d840-83dc-4d72-afb9-dff96c02a994" />

**3. Draw the base profile**

Construct the elongated base profile of length 420 mm and height 30 mm using the line command. Draw an arch from the centre of R110 mm then draw a rectangle of length 120 mm and height of 60 mm as shown in the engineering drawing.

<img width="697" height="561" alt="Lines" src="https://github.com/user-attachments/assets/d641a8dd-d419-461a-bb83-15e906f115f1" />

<img width="437" height="511" alt="image" src="https://github.com/user-attachments/assets/02d73b93-87b6-4096-8278-acf9f5b0698e" />

<img width="1256" height="647" alt="3 2 Sketch-1" src="https://github.com/user-attachments/assets/871e44d9-f84e-4d71-97b7-240caa394991" />

**4. Extrude the base plate**

Finish the sketch and select the enclosed base profile. Use the Extrude command to create the solid base plate with a thickness of 150 mm.

<img width="186" height="218" alt="Finish Sketch" src="https://github.com/user-attachments/assets/1353da90-64bd-4aee-a748-55a4c26a44ad" />

 <img width="466" height="607" alt="Extrude" src="https://github.com/user-attachments/assets/dba0d9cf-461f-4785-a78a-8801ab249ab7" />

**5. Creating circular profile**

Select the side plane and draw a circle of R20 mm and R60 mm from a point which is 150 mm from the centre connect the ends of the circles to the arch using suitable constraints and trim commands.

<img width="536" height="542" alt="Circle" src="https://github.com/user-attachments/assets/f83f9425-b950-4c46-9d96-4f2ff34cf7ff" />

<img width="338" height="482" alt="Constraints" src="https://github.com/user-attachments/assets/c11140b1-8be3-4599-bd37-1ca02a974ded" />

<img width="1232" height="598" alt="3 2 Sketch-2" src="https://github.com/user-attachments/assets/76ea10b2-60fb-470e-8809-eeac8153a7a4" />

**6. Cut the extra openings**

After confirming the dimensions finish the sketch and apply the extrude command set cut option in it and select the extra openings.

<img width="466" height="607" alt="Extrude" src="https://github.com/user-attachments/assets/a6a85917-bbae-4131-8f9b-da727f2245fc" />

<img width="312" height="428" alt="Cut" src="https://github.com/user-attachments/assets/87c25840-125d-4df0-b2b1-8ab7f4350ef6" />

**7. Create the central circular hole sketch**

Select the top curved face of the arch support and create a new sketch. Use the Centre Diameter Circle tool to draw a circle of Ø20 mm at the specified central position.

<img width="1286" height="622" alt="3 2 Sketch-3" src="https://github.com/user-attachments/assets/f3288b45-8586-41e5-9905-3bd7ddef6469" />

**8. Create the central hole**

Finish the sketch and use the Extrude commands Cut operation to remove material through the required portion of the arch support, forming the central circular hole.

**9. Inspect and verify the model**

Rotate the model using the ViewCube and inspect it from different orientations. Verify the mounting holes, arch curvature, rectangular opening, overall dimensions and central circular hole with reference to the engineering drawing.

<img width="757" height="541" alt="3 2 Extrude" src="https://github.com/user-attachments/assets/bf682082-b2a7-4e52-9380-c9d401f3f675" />

**10. Save the completed model**

After completing the modelling operations, save the final design in Autodesk Fusion 360. Ensure that the model is properly formed and all the required features are visible.

**11. Create a drawing file**

Choose Drawing > From Design, select a suitable sheet size, and place the front, top, and right views. Add an isometric view if needed to show the 3D shape clearly.

<img width="1056" height="682" alt="New Drawing" src="https://github.com/user-attachments/assets/f2828fdc-191e-45f7-98ed-4edd806fa24d" />

The Drawing was set to Manual for further processing.

<img width="493" height="541" alt="Drawing pop" src="https://github.com/user-attachments/assets/c466624e-d6a8-409a-b4d6-775bb3090dad" />

**12. Add dimensions and save**

Add the required diameters, radii, distances, and overall dimensions. Arrange the annotations so they are readable and do not overlap the part or one another. Check the drawing against the reference before saving the drawing file.

<img width="250" height="557" alt="Drawing Dimensions" src="https://github.com/user-attachments/assets/67870ec1-e140-49a7-a393-d8267e20a196" />

## INPUT

The given two-dimensional engineering drawing containing the top view, front view, side view and required dimensional details.

A three-dimensional arch support bracket consisting of an elongated base plate with two mounting holes, a curved arch-shaped supporting structure, a rectangular opening and a central circular hole. The completed component was reviewed in an isometric view to verify its geometry and overall appearance.
